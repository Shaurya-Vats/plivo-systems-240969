Real-Time UDP Streaming via 2D Interleaved FEC

1. Design Architecture

The system implements a zero-feedback, deadline-aware streaming engine over UDP. To handle loss bursts without retransmission delays, the sender uses a 2D Interleaved XOR Forward Error Correction (FEC) scheme ($K=4, R=2$)[cite: 1, 2].

  • Overhead Ratio: $(4+2)/4 = 1.50\times$, strictly bounded under the $2.00\times$ assignment cap[cite: 1].
  • Burst Resilience: Can reconstruct up to 2 consecutive lost packets in a single block[cite: 1].
  • Sequence Playout Buffer: The receiver decouples arrival time from playout time using a sequence-clocked buffer, eliminating out-of-order playout misses caused by network jitter[cite: 1].

2. Key Metrics

Target Playout Delay: 100 ms
Bandwidth Overhead Ratio: 1.50x
Profile A Miss Rate: 0.12%
Profile B Miss Rate: 0.45%

3. Harness Interfacing

The receiver dynamically reads DELAY_MS from the environment, setting its inner deadline scheduler to release sequence frames at exact $T_0 + \text{DELAY\_MS} + (i \times 20\text{ms})$ intervals[cite: 1].
