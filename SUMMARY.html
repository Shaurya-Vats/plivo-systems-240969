Plivo Flaky Network: Systems Architecture Summary

1. Design Strategy

The solution utilizes proactive Forward Error Correction (FEC) using XOR block parity. Rather than paying the double RTT penalty of NACK-based retransmission, parity frames are sent immediately following every 2 data frames.

2. Protocol & Wire Format

A custom 9-byte header encapsulates harness payloads:

  • seq (4-byte uint32): Sequence identifier.
  • type (1-byte uint8): Frame classification (0 = Data, 1 = Parity).
  • group_base (4-byte uint32): Sequence identifier of the group origin.

3. System-Level Execution

The receiver processes stream packets out-of-order, maintaining state maps for active FEC groups. Single missing frames per group are instantly reconstructed via XOR operations before immediate dispatch to the target playout socket.
